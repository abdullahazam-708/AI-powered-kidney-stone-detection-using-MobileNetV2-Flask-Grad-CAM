Abstract

What is this Project?

Back Propagation Network is the most commonly used algorithm in training neural networks. It is employed in processing images to implement an automated kidney stone classification.

MR Images may possess noise caused by operator errors — causing inaccuracies in classification. Artificial intelligence combined with neural networks and feature extraction shows great potential in extracting the region of interest.

Decision making is carried out in two stages: Feature Extraction using PCA and Image Classification using BPN. Segmentation is done using Fuzzy C-Mean (FCM) clustering.

Core Algorithms

How It Works

Fuzzy C-Mean Clustering

FCM allows each pixel to belong to multiple clusters with a degree of membership. Unlike hard clustering, FCM handles the overlapping nature of biological tissue boundaries in MRI scans.

1Initialize cluster centers randomly
2Calculate membership matrix U for each pixel
3Update cluster centers using weighted means
4Repeat until convergence criterion met
J = Σ Σ uijm ||xi - cj||²

Principal Component Analysis

PCA reduces the high-dimensional feature space of segmented images into principal components that carry maximum variance — enabling the BPN classifier to work efficiently with fewer features.

1Standardize segmented image features
2Compute covariance matrix
3Extract eigenvalues & eigenvectors
4Project data onto principal components
C = (1/n) XTX  →  Eigendecomposition

Back Propagation Network

A multi-layer feed-forward neural network trained using the back-propagation algorithm. Errors are propagated backwards to adjust weights, enabling precise kidney stone classification.

1Forward pass: compute output from PCA features
2Calculate error at output layer
3Backpropagate error through hidden layers
4Update weights using gradient descent
Δw = -η · ∂E/∂w  (Gradient Descent)
